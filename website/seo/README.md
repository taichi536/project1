# SEO 運用（記事テーマの優先順位づけ）

限られた工数で相談件数を最大にするために、「どの記事を、どの順番で書くか」を数値で決める仕組みです。

## ファイル

| ファイル | 内容 |
|---|---|
| `keywords.csv` | 記事テーマの候補（検索語）の一覧。検索数や公開状況をここに記録する |
| `keywords_list.txt` | キーワードプランナーに貼り付ける用の検索語だけの一覧 |
| `prioritize.py` | 優先順位を計算するスクリプト |
| `plan.md` | 計算結果の記事計画（スクリプトが自動で作る） |

### keywords.csv の列

| 列 | 意味 | 入れる人 |
|---|---|---|
| `keyword` | 検索語 | Claude（追加は誰でも可） |
| `cluster` | テーマのまとまり（まとめ記事1本＋個別記事） | Claude |
| `role` | `pillar`（まとめ記事）／`child`（個別記事）。個別記事はまとめ記事の後に書く | Claude |
| `intent` | 転職意欲の強さ 1〜3（3＝相談につながりやすい） | Claude（Snow-weの感覚で修正可） |
| `difficulty` | 上位表示の難しさ（低・中・高）。検索結果を見て、比較メディアや大手が並んでいれば「高」 | Claude（実際の検索結果を見て修正可） |
| `review_hours` | Snow-we側の確認・加筆にかかる時間（下書きは Claude が作る） | Claude |
| `monthly_volume` | 月間検索数 | **Snow-we（キーワードプランナー）** |
| `status` | `未着手`／`公開済み` | 公開したら更新 |
| `url` | 公開した記事のURL | 公開したら記入 |

## 手順1：月間検索数を調べる（初回のみ・約20分）

1. [Google 広告](https://ads.google.com/) にログインする（アカウントがなければ作成。**広告を出さなくても使えます**。作成時に「エキスパートモードに切り替える」→「キャンペーンを作成せずにアカウントを作成」を選ぶと、支払い情報なしで作れます）
2. 上部メニュー「ツール」→「キーワード プランナー」→「**検索のボリュームと予測のデータを確認する**」
3. `keywords_list.txt` の中身を全部コピーして貼り付け →「開始する」
4. 地域が「日本」、言語が「日本語」になっていることを確認する
5. 右上の「キーワードをダウンロード」→「.csv」でダウンロードする
6. ダウンロードしたCSVを Claude に渡す（`keywords.csv` の `monthly_volume` 列に反映します）

※ 広告を出していないアカウントでは、検索数が「100〜1000」のような幅で表示されます。その場合は中間の値（例：300）を使えば十分です。

## 手順2：記事計画を作る

```
python3 seo/prioritize.py plan --hours 8 --months 3
```

- `--hours`：1か月に Snow-we 側で確保できる確認・加筆の時間
- `--months`：何か月分の計画を作るか

結果は `seo/plan.md` に書き出されます。

### 計算の考え方

```
テーマの価値（期待相談件数/月）
  = 月間検索数 × 上位に入れる確率 × その順位でのクリック率 × 相談に進む率
```

確保できる工数の範囲で、この合計が最大になるテーマの組み合わせを選びます（ナップサック問題）。「まとめ記事を書いてから個別記事」という順序も守るようにしています。
係数（順位ごとのクリック率、難しさごとの確率、意欲ごとの相談率）は `prioritize.py` の冒頭にあり、すべて仮置きです。公開後の実データで見直します。

## 手順3：毎月の見直し（公開後）

1. Search Console →「検索パフォーマンス」→ 期間「過去28日間」→「クエリ」タブ →「エクスポート」→「CSV をダウンロード」
2. 次のコマンドで、「少し直せば伸びる」リライト候補を出す（平均順位4〜20位で表示回数が多いもの）
   ```
   python3 seo/prioritize.py rewrite ダウンロードしたCSV
   ```
3. 公開した記事の `status` を `公開済み` にし、手順2で翌月の計画を作り直す

新しい記事を書くか、既存の記事を直すかは、「追加クリック見込み」と記事計画の「期待相談件数」を比べて決めます。
