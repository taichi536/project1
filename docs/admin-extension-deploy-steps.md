# 拡張機能の配布設定 — 上司向け詳細手順

Chromeブラウザのクラウド管理登録（CBCM）が完了しました（たいちさんのMacが「管理対象ブラウザ」に登録済みです）。
次は、そこに拡張機能を自動配布する設定です。

---

## ステップ① 「管理対象ブラウザ」一覧の確認（まずこれだけ）

1. **https://admin.google.com** にログイン
2. 左メニュー **「デバイス」** → **「Chrome」** → **「管理対象ブラウザ」**
3. 一覧に、たいちさんのMac（ユーザー名 `taichi.endo@snow-we.jp` 等）が表示されているか確認

表示されていない場合は、少し待ってからページを再読み込みしてください（反映まで数分かかることがあります）。

**表示されたら、次のステップ②に進んでください。**

---

## ステップ② 拡張機能を配布リストに追加する

### 2-1. 「アプリと拡張機能」を開く

左メニューで、以下の順にクリックする。

1. **「デバイス」**
2. **「Chrome」**
3. **「アプリと拡張機能」**

### 2-2. タブを切り替える

画面上部にいくつかタブが並んでいる（ユーザーとブラウザ／キオスク など）。

**「ユーザーとブラウザ」** タブを選ぶ（デフォルトで選ばれている場合はそのままでよい）。

### 2-3. 組織部門を確認する

左側に組織部門のツリーが表示されている場合は、一番上（**Snow-we.Inc** 全体）が選ばれていることを確認する。特定の部署だけを選んでいると、そこにしか配布されない。

### 2-4. 拡張機能を追加する

1. 画面右下（または右上）にある **黄色い「＋」ボタン** をクリックする
2. 表示される選択肢の中から **「URLで追加」**（英語表記の場合は "Add Chrome app or extension by URL"）を選ぶ

   **注意: 「IDで追加」ではなく「URLで追加」を選ぶこと。**

3. 入力欄が2つ、または1つ表示される。以下をそのまま貼り付ける。

   **拡張機能ID:**
   ```
   dolbaepfcojfnanjeemkcogbbgopoici
   ```

   **更新用URL（update URL）:**
   ```
   https://ext.143-198-195-132.nip.io/updates.xml
   ```

   ※ 入力欄が1つしかなく、URLだけを聞かれる場合は、URLだけを入力すればよい（IDは自動で読み取られる）。

4. **「保存」** をクリック

### 2-5. インストールポリシーを設定する

1. 追加された拡張機能（「Snow-we スカウト パーソナライズ生成」等の名前で表示されるはず）を一覧からクリックして開く
2. 右側に設定パネルが開く。その中の **「インストールポリシー」** という項目を探す
3. プルダウンから **「強制インストール」**（英語では "Force install"）を選ぶ

   選択肢の例:
   - ブロック
   - 許可
   - **強制インストール** ← これを選ぶ
   - 強制インストール、ツールバーに固定

   「強制インストール」であれば、末尾に「ツールバーに固定」が付いていてもよい。

4. 画面右上の **「保存」** をクリック

---

## ステップ③ 完了の合図

保存が終わったら、その旨をたいちさんに伝えてください。以降はたいちさんの側で、実際に拡張機能が自動でインストールされるかを確認します。

---

## うまくいかない場合

| 症状 | 対処 |
|---|---|
| 「＋」ボタンが見当たらない | 画面を下にスクロールするか、ウィンドウを最大化してみる |
| 「URLで追加」の選択肢がない | 「ID で追加」しかない場合は、拡張機能IDだけを入力して追加し、その後の設定でURLを別途聞かれないか確認する（聞かれない場合はここで一度立ち止まって連絡してほしい） |
| 「インストールポリシー」の項目が見当たらない | 追加した拡張機能の名前をクリックした後の画面全体をスクロールして探す |
| 保存後もエラーが出る | エラーメッセージの文言をそのまま教えてほしい |
