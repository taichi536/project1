# 【依頼】Chromeブラウザのクラウド管理登録のお願い

社内で使用している業務用Chrome拡張機能を、メンバー全員に自動で配布・更新できるように
したく、Google管理コンソールでの設定をお願いしたいです。

お願いしたい作業は **2つ** です。所要時間は合わせて10分程度です。

- **作業① 登録トークンの発行**（5分）
- **作業② 拡張機能の配布設定**（5分）

※ 追加費用はかかりません。Google Workspaceに標準で含まれる機能です。

---

## なぜ必要か

現在、拡張機能の更新をメンバーが手動で行っており、更新を忘れた人の環境で
**データが記録されない不具合が発生しました**（1週間で約300件の記録漏れ）。

自動更新にすることで、この問題を根本的に防ぎたいと考えています。

---

## 作業① 登録トークンの発行

### 手順

1. **https://admin.google.com** にアクセスしてログイン

2. 左のメニューから **「デバイス」** をクリック

3. その下に出てくる **「Chrome」** をクリック

4. さらにその下の **「管理対象ブラウザ」** をクリック

5. 画面の中に **「登録トークン」** というボタン、またはタブがあります
   - 見つからない場合は、画面右下または右上の **「＋」** ボタンを探してください

6. クリックすると、トークンを作成する画面が出ます
   - **「組織部門」** を選ぶ欄があれば、一番上（会社全体）のままで大丈夫です
   - **「作成」** または **「生成」** を押します

7. **英数字とハイフンの長い文字列**（例: `a1b2c3d4-5678-90ab-cdef-1234567890ab`）が
   表示されます

8. **この文字列をコピーして、遠藤までお送りください**

以上で作業①は完了です。

### 補足

このトークンは「どのブラウザが自社のものか」を識別するためのものです。
これを設定したブラウザが管理コンソールの一覧に表示されるようになります。

## 作業② 拡張機能の配布設定

**作業①の後、遠藤が各PCの設定を行います。その完了報告を受けてから**
以下をお願いします（先に行っても問題はありませんが、効果が出ません）。

### 手順

1. **https://admin.google.com** にアクセス

2. 左のメニューから **「デバイス」** → **「Chrome」** → **「アプリと拡張機能」** をクリック

3. 上部のタブから **「ユーザーとブラウザ」** を選択

4. 画面 **右下の黄色い「＋」ボタン** にマウスを合わせます
   - いくつかの選択肢が出てきます

5. その中から **「URLで追加」**（または「Add Chrome app or extension by URL」）を
   クリックします
   - ※「IDで追加」ではなく **「URLで追加」** です

6. 入力欄が出るので、以下をそのまま貼り付けてください

   **拡張機能ID:**
   ```
   dolbaepfcojfnanjeemkcogbbgopoici
   ```

   **URL:**
   ```
   https://ext.143-198-195-132.nip.io/updates.xml
   ```

7. **「保存」** を押します

8. 一覧に追加された拡張機能をクリックし、右側に出る設定の中の
   **「インストールポリシー」** を **「強制インストール」** に変更します

9. 画面右上の **「保存」** を押します

以上で作業②は完了です。

## よくある質問

**Q. セキュリティ上の問題はありませんか**

A. この拡張機能は社内で開発したもので、外部には公開していません。
配布元のサーバーも自社で管理しているものです。

**Q. メンバーのブラウザの中身が見えるようになりますか**

A. 管理コンソールで確認できるのは、ブラウザのバージョンや適用中のポリシーなど、
管理に必要な情報のみです。閲覧履歴などは表示されません。

**Q. 途中で分からなくなったら**

A. 画面のスクリーンショットを撮って遠藤にお送りください。

## 参考: 遠藤側の作業（管理者の対応は不要です）

作業①のトークンを受け取ったあと、各メンバーのMacで以下を実行します。

```bash
sudo defaults write /Library/Preferences/com.google.Chrome \
  CloudManagementEnrollmentToken -string "受け取ったトークン"
```

Chromeを再起動すると、そのブラウザが管理コンソールの
「管理対象ブラウザ」一覧に表示されるようになります。
