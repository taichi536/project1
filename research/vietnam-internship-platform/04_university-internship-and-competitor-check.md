# ①大学の卒業実習制度と時期 ②競合サービスの実物調査

調査日: 2026-09-25

> **調査の制約:** この調査環境のネットワーク設定で、大学サイト（neu.edu.vn / ueh.edu.vn など）と競合サイト（topcv.vn / ybox.vn / glints.com / studentjob.vn）のページを直接開けなかった。そのため**検索結果に出るページタイトル・抜粋から拾える範囲**でまとめている。掲載内容を1件ずつ数える実測（手当の記載率など）はできていないので、§2.4 の手順で現地のブラウザから実施する。

## 0. 結論サマリ

| 観点 | 所見 | 事業への示唆 |
|---|---|---|
| 制度 | 実習の中身と期間は大学が決める。国の規程（Circular 08/2021）は枠組みだけ。ほぼすべての大学で**卒業前の実習（約10〜15週）が必修**。大学によっては**在学中の中間実習**（FTU 5週・200時間など）や、**2年次の業界見学実習**（HCMUT）もある | 「卒業実習の受け入れ先探し」は毎年必ず発生する需要。**毎年、学生の供給が生まれる** |
| 時期 | 大学ごと・学部ごとにバラバラ。例：NEU 秋期は8月3日開始（17週）、NEU 春期は12月22日開始、UEH は「学期前半」「学期後半」の年2回、HUST SoICT は**年3回**（10〜1月、3〜6月、6〜9月）、FPT大は6学期目に4〜8か月の OJT | 需要のピークは1回ではなく**通年で分散**。大学・学部別の実習カレンダーをデータ化すると営業と集客の武器になる |
| 実習先探し | **学生が自分で探す大学が多い**。企業と大学の提携は限られる | プラットフォームの入り口として最適 |
| 形骸化 | 「**押印（会社の赤い丸印）付きの実習証明書だけ欲しい**」学生がいる。証明書の押印を代行する業者まで存在する。受け入れても仕事を任せない企業もある（Dân trí 2025） | **「本当に仕事をさせる実習」と「実習証明の電子化・検証」**が差別化ポイントになり得る |
| 競合の掲載量 | インターン求人は TopCV **2,222件**（ホーチミン 1,115件）が最多。VietnamWorks は約110件、LinkedIn は218件、Glassdoor は592件 | TopCV が圧倒的。**件数で正面から戦うのは不利** |
| 競合の特徴 | YBOX は自社のインターン募集で「**押印・修了証明・推薦状**」を特典として打ち出している。ITviec には「Internship Accepted」ラベルがある。FresherUP は無料だが規模は不明 | 学生が求めているのは「求人の数」だけでなく「**単位・証明・推薦状につながること**」 |

## 1. 大学の卒業実習の制度と時期

### 1.1 国の制度

- 学部教育の規程は **Circular 08/2021/TT-BGDĐT**（大学教育規程、2021年5月施行）。卒業要件（必要単位、GPA 2.0以上など）を定めるが、**実習の中身・期間・時期は各大学が教育プログラムの中で決める**。
- 労働法上は、企業内実習は最長3か月で、労働契約の対象外（`01`・`02` 参照）。

### 1.2 主要大学の例

| 大学 | 実習の種類 | 期間・単位 | 時期 | 実習先の探し方・特徴 |
|---|---|---|---|---|
| **国民経済大（NEU・ハノイ）** | 卒業実習＋卒業論文 | 合計15週（**実習12週＋論文の報告・審査3週**）。数理経済学部では17週の例も。プログラム単位の75%以上を取っていることが条件 | 年に複数回。例：**秋期 2026年8月3日開始**（K65 第1回）、**春期 2025年12月22日開始**（K64 第2回） | 学部ごとに計画を出す |
| **経済大（UEH・ホーチミン）** | 「実習と卒業」科目 | 学部・プログラムで異なる（計画書のPDFに記載） | **年2回**（学期前半＝年の前半、学期後半＝年の後半）。2026年8月の実習ガイドもある | 学部ごとに指導教員の登録と書式を提供 |
| **外国貿易大（FTU・ハノイ）** | ①中間実習 ②卒業実習 | ①**5週・200時間以上**（全10週の枠内）②**10週**（指導教員が付く）。論文を書かない場合は卒業実習＋3単位の追加科目 | ①年に最大5回（各学期の前半・後半＋夏）②4年次の最終学期 | 中間実習がある＝**2〜3年生にも需要がある** |
| **ハノイ工科大（HUST）SoICT** | 企業実習（必修） | **フルタイム1週＝1単位** | **年3回**：第1期 10〜1月（9月登録）、第2期 3〜6月（2月登録）、第3期（夏）6〜9月（5月登録） | **学内システムで企業がテーマを登録し、学生が志望を出してマッチング**（例：企業のテーマ登録 9/4〜9、学生の志望 9/9〜21、企業の選考 〜9/29） |
| **ホーチミン工科大（HCMUT）** | ①2年次の業界見学実習 ②卒業実習 | 不明 | 不明 | 卒業審査委員に企業側の委員が1名以上入る |
| **FPT大** | OJT（On-the-Job Training） | **4〜8か月** | **6学期目** | 大学が数千社の提携企業ネットワークを持つ。手当の有無はプロジェクト次第 |
| **RMIT ベトナム** | インターン（単位あり） | **12週** | ビジネス系は最終学年に任意、デザイン・コミュニケーション系は最終学年に必修 | 大学のインターンプログラムに企業が登録 |

### 1.3 年間カレンダー（概略）

| 月 | 大学の動き | インターン需要 |
|---|---|---|
| 9月 | 第1学期開始。HUST 第1期の登録 | 秋開始の実習先探し |
| 10〜1月 | 第1学期。12〜1月は試験 | HUST 第1期の実習中。NEU の春期は12月下旬開始 |
| 1月下旬〜2月 | **テト休暇（7〜10日）** | 採用活動が止まる |
| 2〜6月 | 第2学期。4〜5月は試験。HUST 第2期（3〜6月） | 春の卒業実習 |
| **6〜8月** | **夏休み・夏学期** | **インターン需要のピーク**（HUST 第3期、自主的なインターン） |
| 8月 | NEU 秋期の実習が開始 | 卒業実習 |

> 大学・学部ごとの差が大きいので、上の表は目安。**インタビュー（`03`）で学生と大学キャリアセンターに「自分の学部の実習時期」を必ず聞く**。

### 1.4 実習の形骸化

- 大学は学生に実習先を自分で探させることが多く、企業と大学の提携は限られる。評価も学生の報告書が中心（Dân trí, 2025年4月）。
- 結果として、
  - 「働かなくてよいので、期限までに証明書にサインだけしてほしい」という学生の投稿がある
  - **実習証明書の押印を代行する業者**が存在する（例：dichvuxindau.com）
  - 受け入れても計画がなく、学生が「座っているだけ」の企業がある
- 証明書は、会社の**赤い丸印が鮮明に押されていること**が条件とされる。
- 競合の YBOX も、自社インターン募集で「3か月以上・KPI 80%以上で押印、修了証明、推薦状」を特典として明示している。**押印・証明が学生への実質的な報酬になっている**。

### 1.5 事業への示唆

1. **大学の実習制度に組み込む**のが最短の集客ルート。HUST SoICT のように「企業がテーマを登録し、学生が志望を出す」仕組みを持つ大学は少ない。**それを外部のプラットフォームとして提供する**案が考えられる。
2. **「実際に仕事をした」ことが証明される実習**：業務内容・期間・評価をプラットフォーム上で記録し、企業の確認付きの電子証明を発行する。押印代行と差別化でき、学生の履歴書にも使える。**大学側の評価の負担も減らせる**。
3. **需要は通年で分散**：夏（6〜8月）がピーク、テト前後は谷。営業・広告の年間計画はこれに合わせる。
4. **ターゲット学年を広げられる**：FTU の中間実習、HCMUT の2年次実習、1年生から探す学生もいるので、4年生だけに絞る必要はない。

## 2. 競合サービスの実物調査

### 2.1 インターン求人の掲載量（検索結果のタイトルから取得）

| サービス | インターン求人数 | 取得日 | 備考 |
|---|---|---|---|
| **TopCV** | **2,222件**（全求人 42,049件の約5%） | 2026-07-13 | ホーチミンだけで1,115件。人事 43件、金融 41件 |
| Indeed Vietnam | 4,000件以上（「thực tập sinh」で検索） | 2025-10 | 他サイトからの転載を含む |
| Glassdoor | 592件 | 2026-09 | エンジニア 112件、マーケティング 127件 |
| LinkedIn | 218件 | 2026-09 頃 | 外資・英語求人が中心 |
| VietnamWorks | 約110件（「thực tập sinh」） | 2026-09-04 | 検索語で変動（intern 74件、internships 120件、HR Intern 743件は関連求人込みと推測） |
| Glints | 不明 | — | 「全体で1万件以上」とのみ。Panasonic などの掲載例あり |
| ITviec | 不明 | — | 求人に「Internship Accepted」ラベル。3か月のデータインターン等 |
| YBOX | 不明 | — | 職種別カテゴリあり（マーケティング、人事、プログラミング など） |
| FresherUP | 不明 | — | 2025年8月開始。規模を示す公開情報は見当たらない |

→ **インターン求人は TopCV に集中している**。VietnamWorks・LinkedIn は1桁少ない。

### 2.2 サービスごとの特徴（分かった範囲）

| サービス | 応募の流れ | 学生向けの特徴 | 気づき |
|---|---|---|---|
| TopCV | サイト内で応募（TopCV で作った CV を使う） | CV テンプレート（インターン向け37種）、AI での求人おすすめ、アプリ | CV 作成ツールが学生の入口になっている |
| YBOX | 「オンライン応募」ボタン（外部フォームに飛ぶものもある） | インターン／パートタイム／ボランティア／奨学金／イベントを横断して掲載 | 学生メディア兼コミュニティ。押印・証明を特典として打ち出す |
| Glints | サイト内で応募 | キャリア学習コンテンツ | 地域大手。インターンの掲載もある |
| ITviec | サイト内で応募 | 「Fresher Accepted / Internship Accepted」ラベル | IT 特化で、インターンは副次的 |
| VietnamWorks | サイト内で応募 | — | インターンは少ない |
| FresherUP | サイト内で応募 | インターン・新卒・奨学金・メンタリング・オンライン合同説明会 | コンセプトは近いが、実績は不明 |

### 2.3 分かったこと・分からなかったこと

**分かったこと**
- インターン求人の量では TopCV が圧倒的（2,000件超）。
- 学生向けの価値として「押印・修了証明・推薦状」が実際に使われている（YBOX）。
- 企業側が「インターン可」を明示する仕組み（ITviec のラベル）がある。

**分からなかったこと（→ §2.4 で実測する）**
- 求人のうち**手当が明記されている割合**、手当の金額分布
- **長期（3か月以上）・有給**の求人の割合
- 企業の内訳（ローカル／日系／外資、規模）
- 求人ごとの**企業情報の充実度**（社員の声・写真・仕事内容の具体性）
- 応募から返信までの体験（返信の速さ、選考の流れ）

### 2.4 現地で行う実測の手順（半日〜1日）

**やり方**
1. 対象: TopCV・YBOX・Glints・VietnamWorks・FresherUP の「thực tập / internship」一覧。
2. 各サイトで**新着順に30件ずつ**（計150件）を開き、下の記録表に記入する。
3. 同じ週のうちに一気に行う（掲載は日々変わるため）。

**記録表**（Google スプレッドシートにこの列を作る）

| 列 | 記入内容 |
|---|---|
| site | TopCV / YBOX / Glints / VNW / FresherUP |
| url | 求人の URL |
| company | 企業名 |
| company_type | ローカル中小 ／ ローカル大手 ／ 日系 ／ その他外資 ／ 不明 |
| job_category | マーケティング ／ 営業 ／ 人事 ／ 経理 ／ IT ／ デザイン ／ その他 |
| city | ハノイ ／ ホーチミン ／ その他 ／ リモート |
| allowance_stated | 手当が明記されているか（yes / no / 「thỏa thuận（応相談）」） |
| allowance_min_vnd / allowance_max_vnd | 手当の金額（月額 VND） |
| duration_months | 期間（記載がなければ空欄） |
| hours | フルタイム ／ パートタイム ／ 記載なし |
| conversion_mentioned | 正社員登用に触れているか（yes / no） |
| certificate_mentioned | 押印・実習証明・推薦状に触れているか（yes / no） |
| company_info_richness | 企業情報の充実度 1〜3（1=求人票のみ、2=会社紹介あり、3=写真・社員の声あり） |
| apply_method | サイト内 ／ 外部フォーム ／ メール ／ Facebook |
| posted_date | 掲載日 |

**集計したい指標**
- 手当が明記されている割合と、手当の中央値（サイト別）
- 3か月以上の求人の割合
- 正社員登用に触れている割合
- 押印・証明に触れている割合
- 企業情報の充実度の平均
- 日系企業の割合

これらの数字が、**プロダクトの差別化（手当の明記を必須にする、企業ページを充実させる、実習証明を出す）**の根拠になる。

**あわせて行うと良いこと**
- 学生として実際に登録し、応募してみる（返信の速さ、選考の流れを記録する）
- 企業として無料掲載を試し、審査にかかる日数と管理画面を確認する
- 各サイトの**料金ページのスクリーンショット**を保存する（`02` の料金の裏付けになる）

## 3. 次のアクション

1. §2.4 の実測を現地のブラウザで行う（半日〜1日）。
2. インタビュー（`03`）に**実習の時期・押印・証明についての質問**を追加する（下記）。
3. **大学キャリアセンターへのヒアリング**を優先する。とくに HUST SoICT のように企業マッチングの仕組みを持つ学部、FPT大（OJT）、RMIT。提携の可能性も探る。

### インタビューに追加する質問

**学生向け**
- あなたの学部の卒業実習（中間実習）は、いつ・何週間ですか？ 実習先は自分で探しますか？
- 実習証明書（押印）はどうやって手に入れましたか？ 手に入れるのに苦労しましたか？
- 「実際にやった仕事が記録される実習証明」があったら、価値を感じますか？

**企業向け**
- 大学の卒業実習生の受け入れで、押印・評価書類の対応にどれくらい手間がかかっていますか？
- 実習生を受け入れる学部・時期に偏りはありますか？

**大学向け**
- 実習先の確保と評価で、一番困っていることは何ですか？
- 外部のプラットフォームと連携した例、または連携したい意向はありますか？
