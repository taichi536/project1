# 競合の料金体系 ＆ 法務確認（求人メディア型 vs 人材紹介型 / 外資参入）

調査日: 2026-09-25 / 前提: 公開情報ベースの机上調査。**法務パートは弁護士の確認前の論点整理**であり、法的助言ではない。

換算の目安: 1円 ≈ 175VND（1USD ≈ 26,000VND ≈ 150円 で概算）

---

## 0. 結論サマリ

| 論点 | 結論 |
|---|---|
| 料金水準 | ベトナムの求人掲載は **1件 数千円〜数万円**（例: VietnamWorks 1件30日 260万VND ≈ 1.5万円、TopCV 上位パッケージ 810万VND ≈ 4.6万円）。日本の長期インターン媒体（1名採用 8.8万円〜、月額6.5万円〜）の **1/3〜1/10** が相場感 |
| 課金モデル | 主流は **「無料掲載 ＋ 上位表示・CV閲覧・スカウトの有料化」**（TopCV / Glints / JobOKO / JobsGO / YBOX）。成果報酬は主にヘッドハント（年収の15〜30%）で、ジョブボードではまれ |
| 求人メディア型 | 職業紹介の許可が不要な形で運営できる可能性が高い。ただし **EC法（2026年7月1日施行）上のプラットフォーム登録**、広告規制、個人データ保護法への対応が必要 |
| 人材紹介型 | 2026年6月30日までは **職業紹介の許可 ＋ 保証金3億VND（≈170万円）** が必要。**2026年7月1日から改正投資法で「条件付き事業」から外れた**。ただし施行細則（Decree 352/2025）の改正は2026年12月予定で、**移行期の扱いは弁護士・省当局に要確認** |
| 外資参入 | 職業紹介は WTO で開放を約束していない分野のため、外資は **個別審査（省庁意見照会）**。広告サービスは **合弁（JV）か事業協力契約（BCC）のみ**。一方、日系の先例（en-japan が VietnamWorks 運営会社の90%取得、マイナビが TopCV に出資）はあり、**参入不可ではない** |
| 推奨する初期スキーム | **①メディア型で開始（掲載・スカウト課金）→ ②トラクション後に紹介型（成果報酬）を追加**。法人は「ローカル法人との提携 or JV」か「100%外資でIT/プラットフォーム業として設立」の2案を弁護士と比較 |

## 1. 競合の料金体系

### 1.1 ベトナムのローカル／地域プレイヤー

|---|---|---|---|

| **JobOKO** | **毎月2件まで無料掲載**＋優先表示レベル別の有料パッケージ | 価格表PDFはあるが本調査では取得できず | 学生の手当相場レポートも出している |

### 1.2 日本の参照サービス

| サービス | 課金モデル | 価格 |
|---|---|---|
| **ゼロワンインターン** | 成果報酬型 と 掲載課金型 の選択制 | 成果報酬 **1名8.8万円**（エンジニア・デザイナー14万円）、初期費用0円。掲載課金は3か月で定価約55万円の事例 |
| **Infra** | 前払いの成果報酬型。掲載＋スカウト（月40〜100通） | **9万円〜**（新規企業向けに初回5円キャンペーンあり） |
| **Wantedly** | 月額定額（6／12／24か月契約）。**採用人数による追加費用なし** | ライト **月6.5万円〜**、スタンダード **月13〜15万円**、プレミアムは非公開 |

### 1.3 示唆：料金設計

1. **価格帯は日本の1/3〜1/10が上限。** インターン手当の相場は月200万〜500万VND（≈1.1〜2.9万円）。企業は「インターン1人の獲得に数か月分の手当を超える費用」は払いにくい。ゼロワンの8.8万円をそのまま持ち込むのは難しく、**ローカル企業向けの目安は1名100万〜300万VND（≈0.6〜1.7万円）程度**（仮説。企業ヒアリングで検証が必要）。
2. **学生を集める段階では無料掲載が前提。** 主要競合の多くが無料掲載を提供しているので、掲載料で課金すると供給（求人）が集まらない。
3. **課金ポイントの候補：**
   - スカウト（Infra型）：学生を指名して DM を送る権利
   - 上位表示／特集／企業ページ（Wantedly のストーリー発信に相当）
   - **インターン → 正社員（新卒）転換時の成果報酬**：採用単価が上がるので、ここで回収する（ただし紹介型の法的整理が必要。§2参照）
   - **日系・外資向けプレミアムプラン**（日本語サポート、選考代行、大学連携イベント）：支払意思額が高い層
4. **ベンチマークとして妥当な比較対象** は TopCV（ローカル・若年層）と Glints（地域・若手）。日系向けでは VietnamWorks（en-japan）と TopCV（マイナビ）が既存の選択肢。

## 2. 法務：求人メディア型 vs 人材紹介型

### 2.1 関係する法令（2026年9月時点）

| 法令 | 施行 | ポイント |
|---|---|---|
| **雇用法 Law 74/2025/QH15**（旧 Law 38/2013 を置き換え） | 2026-01-01 | 「職業紹介（dịch vụ việc làm）」は、①職業相談・紹介、②労働者の供給・雇用主への紹介、③労働市場情報の収集・分析・保存・提供 を含む |
| **Decree 352/2025/ND-CP**（旧 Decree 23/2021 を置き換え） | 2026-01-01 | 職業紹介の許可要件：本店・支店（所有 or **2年以上の賃貸**。旧法は3年）、**保証金3億VND**、代表者の要件。許可の有効期間は最長60か月。手続きは省人民委員会、オンライン対応（Decision 4/QĐ-BNV） |
| **改正投資法 Law 143/2025/QH15** | 2026-03-01（条件付き事業リストの変更は **2026-07-01**） | 条件付き事業から38業種を削除。**職業紹介・労働者派遣は削除対象**とされ、事前許可制から事後チェックへ移行 |
| 内務省による Decree 352 改正案 | 政府への提出予定は2026年12月 | 許可の新規発行・再発行・更新・取消・保証金引出しの5手続きをすべて廃止する案 |
| **電子商取引法 Law 122/2025/QH15** | **2026-07-01** | EC を法律レベルで規律。ベトナム語 or .vn の外国プラットフォームは**現地法人設立か代表者の選任が必要**。本人確認・情報開示の義務 |
| Decree 147/2024（インターネットサービス） | 2024-12-25 | SNS 型の機能（ユーザー投稿・コミュニティ）を持つ場合は SNS の許可・届出が論点になる |
| **個人データ保護法 Law 91/2025/QH15 ＋ Decree 356/2025** | 2026-01-01 | 採用・雇用は高リスク処理。必要なデータのみ収集、同意の取得、不採用者データの削除（合意がある場合を除く） |
| 労働法 2019（Law 45/2019/QH14） | 施行中 | 企業内実習（tập nghề）は最長3か月。インターンは労働契約の対象外 |

### 2.2 モデル別の比較

| 項目 | **求人メディア型**（掲載・広告・スカウト課金） | **人材紹介型**（採用成果報酬） |
|---|---|---|
| ビジネス上の位置づけ | 求人情報の掲載場所・マッチングの仕組みを提供するプラットフォーム | 企業に人材を紹介し、採用決定で手数料を得る |
| 職業紹介の許可 | 実務上、大手ジョブボードは EC プラットフォームとして商工省に登録して運営。**ただし雇用法上の「労働市場情報の提供」の範囲が広く、許可の要否はグレー → 要確認** | **2026年6月30日まで：必要**（保証金3億VND、2年以上の事務所賃貸など）<br>**2026年7月1日以降：** 改正投資法で条件付き事業から外れ、事前許可は不要になる方向。ただし Decree 352 の改正が未了のため、**移行期の運用を省当局・弁護士に要確認** |
| EC法上の義務 | **EC プラットフォーム（sàn giao dịch TMĐT）として商工省に登録**、利用規約・個人情報保護方針・紛争処理の公開、掲載企業の本人確認 | 自社サイトで紹介する場合も EC 法の対象になり得る |
| 広告規制 | バナー・特集記事などは広告法の対象。**外資の広告業は JV か BCC のみ**（下記§3） | 通常は該当しない |
| データ保護 | 学生データを企業に渡す＝第三者提供。同意の設計が必須 | 同左＋選考データの削除義務 |
| 立ち上げ難易度 | 低〜中 | 中（2026年7月以降は下がる見込み） |
| 収益性 | 単価は低いが件数でスケール | 単価は高いがインターン単体では低い → **正社員転換時に課金** |

> 用語注: ベトナムの "dịch vụ việc làm"（直訳「雇用サービス」）は、日本の「職業紹介事業」におおむね相当する。

### 2.3 実務上の含意

- **最初はメディア型で始めるのが低リスク。** 掲載・スカウト・企業ページの課金に絞れば、職業紹介の許可を避けやすい（ただしグレー部分は要確認）。
- 紹介型（成果報酬）は、**Decree 352 の改正が出た後（2026年12月以降の見込み）に追加**するのが安全。急ぐ場合は、許可取得（または取得済み現地企業との提携）を前提にする。
- 「インターンの手当を立て替えて企業に請求する」「プラットフォームがインターンと契約する」など、**労働者の供給（派遣）とみなされ得る設計は避ける**。

## 3. 法務：外資としての参入方法

### 3.1 業種ごとの外資規制

| 業種 | WTO 約束 | 外資の扱い（実務） |
|---|---|---|
| 職業紹介（dịch vụ việc làm） | **約束なし（unbound）** | 投資法上の禁止・制限リストには載っていないため参入は可能。ただし**投資登録証（IRC）の審査時に所管省の意見照会が入る個別審査** |
| 広告サービス（CPC 871） | 約束あり（条件付き） | **合弁（JV）か、許可を持つ現地広告会社との BCC のみ。** 100%外資は不可（外資比率は最大99.99%まで可） |
| EC プラットフォーム | — | 外資も可。商工省への登録・届出が必要。EC法で**現地法人か代表者の設置が義務化**（2026年7月以降） |
| IT／ソフトウェアサービス（CPC 84 等） | 約束あり | 一般に100%外資可 |

- CPTPP（日本も加盟）での職業紹介の開放度は本調査では確認できなかった。日越 EPA のベトナム側の開放度は WTO とほぼ同水準とされる。**→ 弁護士に要確認**

### 3.2 2026年の外資手続きの変化

- 改正投資法（2026年3月1日施行）で、外資は **「先に会社を設立 → 12か月以内に IRC を取得」** も選べるようになった。会社登記時に市場参入条件を満たすことを誓約する。
- 条件付き事業の削減（2026年7月1日）で、職業紹介の事前許可は不要な方向。ただし外資の個別審査（WTO 約束なし）は別の論点なので残る。

### 3.3 先例（日系の参入パターン）

| 例 | 形態 |
|---|---|
| en-japan × **VietnamWorks** | 2013年に運営会社 Navigos Group の **90%を約2,200万ドルで取得**（既存大手の買収） |
| マイナビ × **TopCV** | 2022年に資本参加、2023年に追加出資して**持分法適用関連会社化**（少数出資） |
| Glints（シンガポール） | 地域プラットフォームのベトナム展開 |

### 3.4 参入スキームの選択肢

| 案 | 内容 | メリット | デメリット・リスク |
|---|---|---|---|
| **A. 100%外資のIT/プラットフォーム会社** | ソフトウェア／EC プラットフォームの事業目的で設立し、掲載・スカウト課金に限定 | 支配権を完全に持てる。手続きが比較的軽い | 広告枠の販売や成果報酬を始めると、業種の追加や個別審査が必要になり得る。事業目的と実態がずれないように注意 |
| **B. 現地パートナーとの JV** | ベトナム側（例: 大学系企業、人材会社、メディア）と合弁 | 広告・職業紹介まで対応しやすい。大学とのつながりも得られる | パートナー選び、ガバナンス、撤退条項 |
| **C. 既存プレイヤーへの出資・提携** | YBOX などの学生メディアや、許可を持つ人材会社に出資・業務提携 | 学生・企業の基盤をすぐ使える。規制リスクを分担できる | 自社ブランドが育ちにくい |
| **D. 日本から越境運営** | 日本法人がベトナム語サイトを運営 | 初期コストが最小 | **EC法でベトナム語／.vn は現地法人か代表者が必須**、税務、データ越境移転の問題。検証（PoC）段階に限定すべき |
| ✕ 名義借り（ベトナム人名義で設立して実質的に支配） | — | — | **法的リスクが大きく、推奨しない** |

**推奨（仮説）：** PoC は D か C で小さく検証 → 本格参入は **A（メディア型）で開始し、紹介型や広告を増やす段階で B を検討**。どれを選ぶにしても、設立前に現地弁護士の書面意見を取る。

### 3.5 データ保護で追加確認が必要な点

- 学生データを日本側のサーバーや日本の企業に渡す場合の **越境移転の手続き（影響評価書の作成・届出の要否）**
- 未成年（18歳未満の学生）を扱う場合の保護者同意
- 不採用者データの削除期限と、「タレントプールに残す」ことへの同意の取り方

## 4. 弁護士に確認すべき質問リスト

1. 掲載課金・スカウト課金のみのジョブボードは、雇用法 Law 74/2025 の「職業紹介（労働市場情報の提供）」に当たり、許可が必要か？
2. 2026年7月1日以降、Decree 352/2025 の改正前の移行期に、職業紹介の許可・保証金は実務上求められるか？（省人民委員会の運用）
3. 100%外資の会社で、上記のジョブボードを運営できるか？ 事業目的（VSIC コード）はどれを登録すべきか？
4. 企業ページやストーリー記事（Wantedly 型）の有料掲載は「広告サービス」に当たり、JV／BCC が必要か？
5. 外資が職業紹介（成果報酬）を行う場合の所管省の意見照会の実例、期間、通りやすい条件は？ CPTPP（日本）で有利になるか？
6. EC法 Law 122/2025 上、ジョブボードは「EC プラットフォーム」として登録が必要か？ 本人確認の範囲は？
7. 個人データ保護法での越境移転（日本）、影響評価、同意文言のひな形
8. インターンに実習期間3か月超の「長期インターン」を提供する場合、企業側に必要な契約形態（パートタイムの労働契約か実習契約か）
