## 1. 目的と検証したい仮説

このインタビューで「作るか・誰向けに・何で課金するか」を決める材料をそろえる。

| # | 仮説 | 確かめる相手 | 「支持」とみなす基準（目安） |
|---|---|---|---|
| H1 | 学生は**有給の長期インターン**（卒業実習以外）を強く求めているが、見つけにくい | 学生 | 7割以上が「探したが見つけにくかった／探し方が分からない」と具体的なエピソード付きで語る |
| H2 | 学生の主な探索チャネルは Facebook グループと知人で、**信頼性・情報不足（手当・仕事内容・社風）に不満**がある | 学生 | 半数以上が詐欺・ブラック・条件の食い違いなどの不満を自発的に挙げる |
| H3 | 学生は**企業のカルチャー・成長機会**の情報（Wantedly 型）を、手当と同じくらい重視する | 学生 | 企業選びの軸の上位3つに「学べること／人・雰囲気」が入る学生が半数以上 |
| H4 | 企業（特にスタートアップ・日系）は、**意欲の高い学生インターンを継続的に採用したい**が、今のチャネルでは質・量が足りない | 企業 | 半数以上が直近1年でインターンを採用し、今のチャネルに不満がある |
| H5 | 企業は**インターン → 正社員（新卒）転換**を狙っており、そこに対価を払う | 企業 | 転換実績・意向があり、転換1名あたりの支払意思額を具体額で答える |
| H6 | 支払意思額は**インターン1名あたり 100万〜300万VND**、日系は**それ以上** | 企業 | 価格提示に対する反応が「妥当／安い」側に寄る |
| H7 | 企業は Wantedly 型の**企業ページ・ストーリー発信**に価値を感じる | 企業 | 採用広報に時間やお金を使っている、または使いたいと答える |

> 基準の数値は「サンプル15〜20件で傾向を見る」ための目安。統計的な検証ではない。

## 2. 対象者と人数

### 2.1 学生（計 16〜20名）

| セグメント | 人数 | 条件 |
|---|---|---|
| 上位大学（ハノイ） | 4〜5 | 例: 国民経済大、貿易大、ハノイ工科大、FPT大 など |
| 上位大学（ホーチミン） | 4〜5 | 例: 経済大（UEH）、国家大学系、RMIT、FPT大 など |
| 中位大学 | 4〜5 | 両都市から。上位校とのギャップを見るため |
| 日本語学科・日本語学習者 | 3〜4 | 日系企業セグメントの検証用 |
| 新卒1年目（参考） | 1〜2 | インターンから正社員になった／ならなかった経験を聞く |

- 学年は **3〜4年生を中心**に、2年生も少し入れる（「探し始める時期」を知るため）。
- 専攻はビジネス系・IT系・語学系をバランスよく。男女比もおおむね半々にする。
- **インターン経験あり 6割、なし（探している）4割** が目安。

### 2.2 企業（計 12〜15社）

| セグメント | 社数 | 話を聞く相手 |
|---|---|---|
| ローカルスタートアップ（従業員 10〜200名） | 4〜5 | 創業者・採用担当 |
| 日系企業（ベトナム法人） | 4〜5 | 日本人駐在員の管理職＋ベトナム人の人事担当（可能なら両方） |
| 外資・ローカル中堅〜大手 | 3〜4 | 人事・採用マネージャー |
| 大学キャリアセンター（参考） | 1〜2 | 担当者。卒業実習の運用と企業との連携の実態 |

- 条件: **直近1年以内にインターンを受け入れた、または受け入れを検討した**。
- 除外: 人材紹介会社・求人メディアの社員（競合なので別途ヒアリングする）。

## 3. リクルーティング

### 3.1 集め方

| 対象 | チャネル |
|---|---|
| 学生 | 大学の学生クラブ（ビジネス・起業・日本語クラブ）、インターン系 Facebook グループへの投稿、知人紹介（1人から2〜3人紹介してもらう）、日本語学校 |
| 企業 | 日本商工会（JCCH / JBAH）のつながり、ベトナムのスタートアップコミュニティ、LinkedIn、TopCV・YBOX でインターンを募集している企業に直接連絡 |

### 3.2 謝礼（目安・要調整）

- 学生: 20万VND 程度のギフト券・電子マネー（Grab / MoMo など）
- 企業: 謝礼は出さず、**調査結果のサマリー（学生のインターン観レポート）を共有する**ことを対価にする

### 3.3 スクリーナー（学生）

| 質問 | 選択肢 | 判定 |
|---|---|---|
| 大学名・学年・専攻 | 自由記述 | セグメントを割り当てる |
| これまでにインターン経験はありますか？ | 有給 ／ 無給 ／ 卒業実習のみ ／ なし | 割当比率の調整 |
| この1年でインターンを探しましたか？ | はい ／ いいえ | 「いいえ」かつ経験なしなら原則対象外 |
| 探すときに使ったもの（複数選択） | Facebook ／ TopCV ／ YBOX ／ LinkedIn ／ 学校 ／ 知人 ／ その他 | 偏りを確認する |
| 日本語能力 | なし ／ N5〜N4 ／ N3 ／ N2以上 | 日本語セグメントの判定 |
| オンラインで45分話せますか？ | はい ／ いいえ | 「いいえ」なら対象外 |

### 3.4 スクリーナー（企業）

| 質問 | 判定 |
|---|---|
| 業種・従業員数・資本（ローカル／日系／その他外資） | セグメントを割り当てる |
| 直近1年でインターンを受け入れた人数 | 0人で検討もしていなければ対象外 |
| インターン採用に関わる立場 | 意思決定者か実務担当が望ましい |
| 求人媒体・人材紹介の利用経験 | 価格の話ができるかの目安 |

## 4. 実施方法

| 項目 | 学生 | 企業 |
|---|---|---|
| 形式 | オンライン（Google Meet / Zoom）、1対1 | オンライン or 訪問、1対1（日系は駐在員と現地人事を別々に聞くのが望ましい） |
| 時間 | 45分 | 60分 |
| 言語 | ベトナム語（通訳付き）or 英語。日本語学習者は日本語も可 | 日本語・英語・ベトナム語 |
| 体制 | 聞き手1名＋記録係1名（＋通訳） | 同左 |
| 記録 | 同意を得て録音し、文字起こし。個人名は匿名化する | 同左。社名は社内資料のみに記載 |

### 4.1 同意と個人データ（個人データ保護法への対応）

- 開始前に口頭・書面で次を説明し、**同意を記録する**:
  - 調査目的、録音の有無、データの保存期間（例: 調査終了後6か月で削除）、第三者提供なし、途中でやめてもよいこと
- **18歳未満（1年生の一部）は原則対象外**にする（保護者同意の手間を避ける）。
- 録音・メモは限られたメンバーだけが見られる場所に保管する。**このリポジトリには生データを置かない**。

## 5. 学生インタビューガイド（45分）

> 聞き方の原則: **「普段どうしているか」より「最後にやったとき何をしたか」**を聞く。意見ではなく、実際のエピソードと行動を集める。サービス案の説明は最後まで出さない。

### 0. 導入（3分）
- 自己紹介、目的（「学生のインターン探しの実態を知りたい。正解はない」）、録音の同意

### 1. 背景（5分）
1. 大学・専攻・学年、今の生活（授業／アルバイト／クラブ）について教えてください。
2. 卒業後はどんな仕事をしたいですか？ いつごろ決めましたか？

### 2. 直近のインターン探し（15分）★最重要
3. **一番最近インターン（または仕事）を探したときのことを、最初から順番に話してください。**
   - きっかけは何でしたか？（卒業要件？ 経験を積みたかった？ お金？）
   - 最初に何をしましたか？ どこで探しましたか？
   - いくつ応募して、何件返事が来ましたか？ どのくらい時間がかかりましたか？
   - 最終的にどう決めましたか？ 決め手は何でしたか？
4. その中で一番大変だったこと・嫌だったことは何ですか？
5. （Facebook を使った場合）どのグループを使いましたか？ 信用できないと感じた投稿はありましたか？
6. （TopCV などを使った場合）そのサイトの良かった点・不満な点は何ですか？
7. （経験がない場合）なぜまだインターンをしていないのですか？ 何があれば始めますか？

### 3. インターンの中身と条件（8分）
8. （経験者）実際のインターンはどうでしたか？ 募集のときに聞いていた内容と違ったことはありましたか？
9. 手当はいくらでしたか？ **いくらなら「やりたい」と思いますか？ いくら以下なら断りますか？**
10. 無給でもやりたいインターンはありますか？ それはどんな会社・仕事ですか？
11. 週に何日、何か月くらいならできますか？ 授業とどう両立しますか？
12. 卒業実習（学校のインターン）と、自分で探すインターンは何が違いますか？

### 4. 企業選びの軸（7分）
13. インターン先を選ぶとき、大事なことを**3つ**挙げてください。
    - （出てこなければカードで提示: 手当／学べること・成長／会社の知名度／人・雰囲気／正社員になれる可能性／場所・リモート／日系・外資か）
14. 応募する前に、その会社について**知りたいのに分からなかった情報**は何ですか？
15. 社員の話や一日の仕事の様子などの情報があったら、応募の判断は変わりますか？
16. （日本語学習者）日系企業のインターンに興味はありますか？ 不安な点は何ですか？

### 5. コンセプトへの反応（5分）※最後にだけ提示
17. 次のようなサービスがあったら使いますか？ 理由も教えてください。
    > 「有給インターンだけを集めたサイト。企業の雰囲気や社員の声が見られて、気になる会社には『話を聞きに行きたい』ボタンで気軽に連絡できる」
18. 何があれば友達に勧めますか？ 何があれば使わないですか？

### 6. 締め（2分）
19. インターン探しについて、他に言っておきたいことはありますか？
20. 同じような状況の友達を紹介してもらえますか？

## 6. 企業インタビューガイド（60分）

> 聞き方の原則: 価格は**最後に**、**具体的な過去の支出**から聞く。「いくらなら払いますか？」だけに頼らない。

### 0. 導入（3分）
- 目的、録音の同意、調査結果のサマリー共有の約束

### 1. 会社と採用の概要（7分）
1. 事業内容、従業員数、ベトナムでの採用体制（人事の人数、決裁者）を教えてください。
2. 年間の採用人数を、新卒・中途・インターン別に教えてください。

### 2. インターン採用の目的と実態（15分）★最重要
3. **直近で受け入れたインターンについて、募集から受け入れまで順に教えてください。**
   - 何のために受け入れましたか？（人手／将来の採用候補／大学との関係／CSR）
   - どこで募集しましたか？ 何人応募があり、何人受け入れましたか？
   - 選考に社内で何時間くらいかかりましたか？
4. 受け入れたインターンの**質**に満足していますか？ 良かった例・困った例を教えてください。
5. 手当・期間・勤務日数はどうしていますか？ そう決めた理由は何ですか？
6. 大学の卒業実習生と、自社で募集したインターンをどう使い分けていますか？
7. インターンから正社員になった人は何人いますか？ **正社員への転換は狙っていますか？**
8. （日系）日本人管理職とベトナム人人事で、インターンに期待することにズレはありますか？

### 3. 採用チャネルと費用（12分）
9. 使っている採用チャネルをすべて挙げてください（TopCV、VietnamWorks、Facebook、大学、紹介会社など）。
10. **直近1年の採用関連の支出**を、ざっくりでよいのでチャネル別に教えてください。
    - 掲載費、有料オプション、紹介手数料（年収の何%）、合同説明会の出展費など
11. 一番効果があったチャネルと、一番期待外れだったチャネルはどれですか？ 理由も教えてください。
12. 新卒・若手を1名採用するのに、実際いくらかかっていますか？（広告費＋人件費の感覚でも可）

### 4. 採用広報（8分）
13. 学生に会社の魅力を伝えるために、何かしていますか？（SNS、社員インタビュー、イベント など）
14. 学生から「知られていない」「誤解されている」と感じることはありますか？
15. 会社の雰囲気や社員の声を発信できるページがあれば、使いたいですか？ 誰が書きますか？

### 5. コンセプトと価格（12分）
16. 次のようなサービスをどう思いますか？
    > 「意欲の高い学生の有給長期インターンに特化した採用サービス。会社のストーリーを発信でき、学生にスカウトも送れる。インターンから正社員の採用までつなげられる」
17. 一番価値を感じる機能はどれですか？（掲載／スカウト／企業ページ／正社員転換の支援／日本語サポート）
18. **料金の聞き方（Van Westendorp 法の簡易版）** — それぞれの課金形態について:
    - 「高すぎて使わない」と感じる金額は？
    - 「高いが、検討はする」金額は？
    - 「お得だ」と感じる金額は？
    - 「安すぎて質が不安になる」金額は？

    | 課金形態 | 聞く単位 |
    |---|---|
    | インターン採用の成果報酬 | 1名あたり |
    | 正社員転換の成果報酬 | 1名あたり |
    | 月額（掲載＋スカウト使い放題） | 月あたり |

19. 決裁は誰がしますか？ いくらまでなら担当者の判断で使えますか？
20. 導入するとしたら、最大の不安は何ですか？

### 6. 締め（3分）
21. 他に話を聞くべき会社や人を紹介してもらえますか？
22. サービスの試作版ができたら、試しに使ってもらえますか？（→ 見込み顧客リストに入れる）

## 7. 記録と分析

### 7.1 インタビュー直後の記録シート（1件ごと、30分以内に記入）

| 項目 | 記入内容 |
|---|---|
| ID・セグメント・日付 | 例: S-HN-03 / 上位校・ハノイ / 2026-10-xx |
| 一番印象的な発言（原文のまま） | 1〜3個 |
| 行動の事実 | 使ったチャネル、応募数、かかった期間、手当の金額、支出額 |
| 困りごと（ペイン） | 箇条書き |
| 仮説 H1〜H7 への判定 | 支持 ／ 反証 ／ 不明、それぞれ根拠を一行 |
| 新しく出てきた仮説・驚いたこと | 自由記述 |
| 次のアクション | 紹介先、見込み顧客リストへの追加 など |

### 7.2 全件終了後の分析

1. **アフィニティ分析**: 発言を付箋（Miro / FigJam）に書き出し、困りごと・行動・価値観ごとにまとめる。
2. **仮説の判定表**: H1〜H7 ごとに支持・反証・不明の件数と、代表的な発言を並べる。
3. **セグメント比較**: 上位校と中位校、日系とローカルで違いが出た点を整理する。
4. **価格の整理**: 企業の回答から、許容できる価格帯（「高いが検討する」と「お得」の間）をセグメント別に出す。
5. **判断**: 作るかどうか、最初のターゲット（学生・企業のどのセグメントか）、最初の課金モデルを決める。

### 7.3 スケジュール案（4週間）

| 週 | やること |
|---|---|
| 1週目 | ガイドのベトナム語訳、スクリーナーの配布、日程調整、パイロット（学生1・企業1）でガイドを修正 |
| 2〜3週目 | 本番のインタビュー（学生 16〜20・企業 12〜15）。毎日、記録シートを記入 |
| 4週目 | 分析、判定表の作成、次の意思決定のミーティング |

## 8. よくある失敗と対策

| 失敗 | 対策 |
|---|---|
| サービス案を先に説明してしまい、「いいですね」しか返ってこない | コンセプトは最後に一度だけ提示する。それまでは過去の行動だけを聞く |
| 「使いますか？」への Yes を需要と思い込む | 実際の行動（すでにお金・時間を使っているか）を重視する。企業には試作版の利用約束、学生には友人紹介など「コストのある行動」を求める |
| 通訳を挟むとニュアンスが落ちる | 重要な発言はベトナム語の原文も記録する。通訳には事前にガイドの意図を説明しておく |
| 上位校・知人経由の学生に偏る | セグメント別の割当を守り、中位校はクラブや Facebook 経由でも集める |
| 日系企業で駐在員の意見だけを聞く | 現地の人事担当にも別枠で話を聞く |
