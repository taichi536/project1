# ベトナム向けインターンシッププラットフォーム 初期リサーチ

調査日: 2026-09-25 / 位置づけ: 事業検討の叩き台（一次情報で要検証の項目あり）

参照モデル: ゼロワンインターン・Infra（長期有給インターン特化の求人メディア）、Wantedly（共感・カルチャー軸の採用SNS）

## 1. 結論サマリ

| 観点 | 所見 |
|---|---|
| 需要（学生側） | 大学生は約210万人、2030年には300万人超を国が計画。若年失業率は2025年Q3に9.03%と統計開始以来の最高、大卒の最大6割が専攻と無関係の職に就く。**「実務経験を積む手段」への需要は強い** |
| 需要（企業側） | 採用難・スキルミスマッチが課題。インターンは「卒業要件の実習（無給中心）」と「企業主導の採用直結型（有給 300〜800万VND/月）」に分かれ、**後者の市場が本命** |
| 競合 | 総合型は TopCV（マイナビ出資、若年層に強い）と VietnamWorks、IT は ITviec / TopDev。学生特化は YBOX・StudentJob・Internship.edu.vn・FresherUP（2025年8月開始）など。ただし**「長期有給インターン × 企業カルチャー発信」に特化した強いプレイヤーは見当たらない** |
| 最大の競合は Facebook | 学生の約38%が Facebook 経由で仕事を探すという調査あり。非公式グループが事実上の流通チャネル |
| 規制 | インターンは労働契約外・最長3か月・給与支払い義務なし。職業紹介は許可制（保証金3億VND等）で、外資の参入は WTO 非約束分野のため個別審査。2026年1月施行の個人データ保護法で採用データの扱いが厳格化 |
| 仮説 | 「Wantedly 的なカルチャー発信 ＋ ゼロワン/Infra 的な有給長期インターン特化」を、**日系・外資・ローカルスタートアップ**向けに提供する余地がある。ただし参入形態（外資規制）とマネタイズ（学生インターンの採用単価が低い）が最大の論点 |

## 2. 市場環境

### 2.1 学生・若年層
- 高等教育の在籍者数: 2023–24年度で約204万人（公立161万・私立42万）。2030年に300万人超が国家目標。
- 若年（15–24歳）失業率: 2025年Q3 9.03%（2014年の統計開始以来最高）、Q4 9.04%。NEET は約140万人（10.2%）。
- 大卒者の毎年10万人超が失業、最大60%が専攻と無関係の職に就く＝**スキル・経験のミスマッチ**。
- Gen Z は2030年に労働力の約34%を占める見込み。「安定」より「目的・成長」を重視する傾向（Manpower）。

### 2.2 求人メディア市場
- ベトナムの求人サイト・クラシファイド市場: 2025年 約1.86億USD、2031年まで CAGR 12.3% で約3.75億USD 予測（Ken Research。調査会社推計のため参考値）。
- 求人市場は「言語 × 職種」で分断: 総合＝VietnamWorks / TopCV、IT＝ITviec / TopDev。

### 2.3 インターンの実態
| 種類 | 内容 | 手当の目安 |
|---|---|---|
| 卒業実習（大学が送り出す） | カリキュラム上の必修。期間固定・短期 | 無給が中心。出ても 50万〜200万VND/月 |
| 企業主導の採用型インターン | 企業が募集し、採用に繋げる | 300万〜800万VND/月（職種による） |
| 全体平均 | — | 200万〜500万VND/月（JobOKO 2026年版レポート） |

→ 日本の「長期有給インターン」に近いのは後者。**このセグメントに絞ったメディアが差別化の軸**になり得る。

## 3. 競合マップ

### 3.1 ローカル総合型
| サービス | 特徴 | 備考 |
|---|---|---|
| **TopCV** | CV作成ツール発。若年層・新卒に強く、登録者約690万人（2023年時点）、トラフィック国内No.1。「thực tập sinh」求人は約2,200件掲載 | **マイナビが出資し持分法適用関連会社化**。日系大手はすでにこの市場に入っている |
| VietnamWorks | 最古参の大手。中堅〜管理職寄り | — |
| CareerViet / CareerLink / JobOKO / Vieclam24h | 総合・ブルーカラー寄り含む | インターン求人も扱うが特化ではない |

### 3.2 IT特化
| サービス | 特徴 |
|---|---|
| ITviec | IT人材の定番。給与レポート等のコンテンツ強い |
| TopDev | IT。イベント・レポートで集客 |

### 3.3 学生・若手特化（直接競合）
| サービス | 特徴 |
|---|---|
| **YBOX** | 学生コミュニティメディア。インターン・ボランティア・奨学金・イベント情報。掲載無料モデル |
| StudentJob.vn | 学生向けバイト・インターン |
| Internship.edu.vn | インターン特化 |
| Intern.vn | 有給インターン募集 |
| **FresherUP** | 2025年8月ホーチミンで開始。学生〜経験2年以下向け。インターン・新卒求人・奨学金・メンタリング・オンライン合同説明会を無料提供 |
| Glints | シンガポール発。若手・インターン求人とキャリア学習コンテンツ |
| LinkedIn | 外資・上位大学層で利用 |

### 3.4 非公式チャネル
- **Facebook グループ**（例: 「Internships & Jobs in Vietnam | Thực tập & Việc làm」など）。学生の約38%が Facebook で仕事を探すという調査（Q&Me）。
- 大学のキャリアセンター・教員の紹介、学生団体（クラブ）経由。

### 3.5 日系向けの隣接プレイヤー
- JVJ（Japan Vietnam Jobs）、CareerCross、RGF Vietnam など日本語人材の紹介・求人。
- 日本人学生向け「ベトナム長期インターン」送り出し（CareerLink Asia 等）。→ 本件とはターゲット逆方向だが、パートナー候補。

### 3.6 ポジショニング（仮説）

## 4. 規制・法務（要専門家確認）

| 項目 | 内容 | 事業への影響 |
|---|---|---|
| 労働法（2019年労働法） | 企業内実習（thử việc とは別の「học nghề / tập nghề」）の期間は最長3か月。インターンは労働契約の対象外で最低賃金・社会保険の適用なし。企業に給与支払い義務なし。実習名目での労働搾取は禁止 | 「有給」をプラットフォーム側の掲載基準にすることが差別化・安全策になる。3か月超の長期インターンの法的整理は要確認 |
| 職業紹介ライセンス（Decree 23/2021 → 2026年1月から Decree 352/2025。**2026年7月から条件付き事業外へ。詳細は `02_pricing-and-legal.md`**） | 職業紹介事業は許可制。安定した事務所、保証金3億VND 等の要件 | **求人広告メディア（掲載課金）なのか、人材紹介（成果報酬）なのか**で必要許認可が変わる可能性。ビジネスモデル設計と同時に確認必須 |
| 外資規制 | 職業紹介サービスは WTO で開放を約束していない分野。外資参入は個別審査 | 日本法人からの100%出資は難航の可能性。ローカルパートナー・ローカル法人・既存プレイヤーとの提携などの参入形態を検討 |
| 個人データ保護法（Law 91/2025/QH15、2026年1月1日施行）＋ Decree 356/2025 | 採用・雇用は高リスク処理として規定（第25条）。採用に関連するデータのみ収集、候補者同意必須、不採用時はデータ削除（合意がある場合を除く） | 同意取得フロー、データ保持期間、企業へのデータ共有設計を最初から組み込む |

## 5. 日本モデルとの対応づけ

| 日本サービスの要素 | ベトナムでの適合性 | コメント |
|---|---|---|
| 長期有給インターン特化（ゼロワン/Infra） | ◎ | 若年失業・経験不足という課題に直結。ただし「長期」の定義は法定3か月を踏まえ再設計 |
| 企業ストーリー・カルチャー発信（Wantedly） | ○ | Gen Z の「目的重視」志向と合う。一方、給与・手当の明示ニーズも強いので条件情報も併記 |
| 「話を聞きに行きたい」カジュアル面談 | ○ | 応募ハードルを下げる。Facebook 上の DM 文化とも近い |
| 企業側の掲載課金・成果報酬 | △ | インターン単体の採用単価は低い。**新卒採用への転換時の課金**や、日系企業向けプレミアム課金で補う設計が必要 |
| 大学との連携 | ◎（必須） | 卒業実習が制度化されているため、大学キャリアセンター・学部との提携が学生獲得の近道 |

## 6. 狙い目になりうるセグメント（仮説）

1. **日系企業 × ベトナム人学生**
   ベトナム進出日系企業は多く、日本語・IT人材の採用ニーズが強い。日本側の運営知見・日本語での企業サポートが差別化になる。ただし TopCV（マイナビ）と正面で重なるため、「インターン→新卒採用」の育成パイプラインに寄せる。
2. **ローカルスタートアップ × 上位大学の意欲層**
   Wantedly 初期と同じ構図。採用予算は小さいがカルチャー発信ニーズは高い。
3. **IT/デジタル職のプロジェクト型インターン**
   ITviec/TopDev は経験者寄り。学生向けの実務課題型インターンは手薄な可能性。
